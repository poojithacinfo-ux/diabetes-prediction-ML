# 🩺 Diabetes Prediction using Machine Learning

## 📌 Overview

This project predicts whether a person has diabetes based on medical data such as glucose level, BMI, age, etc.

Multiple machine learning models are implemented and compared to identify the best-performing model.

---

## 🎯 Objectives

* Build a diabetes prediction model
* Compare multiple ML algorithms
* Evaluate using performance metrics
* Visualize results using graphs
* Extract meaningful insights from data

---

## 📊 Dataset

* Pima Indians Diabetes Dataset
* Features include:

  * Pregnancies
  * Glucose
  * Blood Pressure
  * BMI
  * Age
  * Outcome (0 = No Diabetes, 1 = Diabetes)

---

## 🧹 Data Preprocessing

* Replaced invalid zero values with median
* Removed duplicates
* Checked missing values
* Applied feature scaling using StandardScaler

---

## 🤖 Machine Learning Models Used

* Logistic Regression
* Decision Tree
* Random Forest
* K-Nearest Neighbors (KNN)
* Support Vector Machine (SVM)
* Naive Bayes

---

## 📈 Evaluation Metrics

* Accuracy
* Precision
* Recall

---

## 📊 Visualizations

* Model Accuracy Comparison
* Precision vs Recall Graph
* Confusion Matrix
* ROC Curve
* Feature Importance

---

## 🔍 Key Insights

* Random Forest performed best overall
* High recall is important in medical diagnosis to avoid missing patients
* Glucose level is the most influential feature

---

## 🧠 Conclusion

This project demonstrates how machine learning can assist in early detection of diabetes.
By comparing multiple models and analyzing results, we can identify the most effective approach for prediction.
